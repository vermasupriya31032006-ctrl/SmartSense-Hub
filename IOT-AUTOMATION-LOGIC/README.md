# IoT Automation Logic

## Overview
This project demonstrates a simple IoT automation system using ESP32 and a DHT22 temperature and humidity sensor.

## Objective
To automate an action based on sensor readings.

## Components Used
- ESP32
- DHT22 Sensor
- LED
- 220Ω Resistor
- Wokwi Simulator

## Automation Logic
- Read temperature and humidity values.
- If temperature exceeds the predefined threshold, the LED turns ON.
- If temperature is below the threshold, the LED remains OFF.

## Features
- Real-time sensor monitoring
- Automatic decision making
- LED alert system
- Serial Monitor output
