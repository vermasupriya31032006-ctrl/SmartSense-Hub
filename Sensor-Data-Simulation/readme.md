# Sensor Data Simulation

This module simulates environmental monitoring using a DHT22 sensor with an ESP32. The sensor provides temperature and humidity readings in real time.
# Sensor Data Simulation

## Overview
This project simulates environmental monitoring using a DHT22 sensor connected to an ESP32.

## Components
- ESP32
- DHT22 Sensor

## Features
- Reads temperature
- Reads humidity
- Displays live values in the Serial Monitor

## Output

### Circuit
### Serial Monitor


## Technologies Used
- ESP32
- Wokwi
- Arduino IDE
- C++
