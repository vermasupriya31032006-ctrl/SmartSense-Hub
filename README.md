# SmartSense Hub

A beginner-friendly IoT project developed using ESP32 and the Wokwi simulator. The project demonstrates GPIO control, sensor integration, and automation concepts through practical simulations.

## Features

- ESP32-based simulation
- LED control using GPIO
- Virtual hardware testing in Wokwi
- Modular project structure
- Easy to extend with sensors and automation

## Current Demonstration

### LED Blink

The LED is connected to GPIO 2 of the ESP32 and blinks every second. This verifies the basic hardware setup and digital output functionality.



## Technologies Used

- ESP32
- Arduino IDE
- Wokwi Simulator
- C++
